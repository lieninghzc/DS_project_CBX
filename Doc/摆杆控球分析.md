# 摆杆控球动力学分析

## 坐标系

```
        左端(0cm)                    右端(25cm)
   y=0  ├─────────────────────────────┤  y = L·sinθ
                  O(12.5cm)
```

- 摆杆长 L=25cm，绕中心 O 旋转
- 舵机控制角速度 ω = dθ/dt
- 左端高度始终为 0（参考面）
- 右端高度 = L·sinθ ≈ L·θ（小角度）

## 物理模型

小球受力：重力分量 = g·sinφ，φ 为摆杆倾角。

```
小球加速度 a = g·sinφ ≈ g·φ = g·θ
```

**关键**：摆杆倾角 θ 决定小球加速度，舵机控制的是 dθ/dt（角速度），形成二阶系统：

```
舵机转速 ω ──积分──▶ 摆杆角 θ ──g倍──▶ 小球加速度 a ──积分──▶ 速度 v ──积分──▶ 位置 x
```

## 从 (x₀, v₀) 移动到 y 的最优策略

### 理想情况（无摩擦、无限加速度）

经典**时间最优 bang-bang 控制**：

1. **加速段**：舵机全速旋转使摆杆倾斜产生最大加速度 +a_max
   - 小球加速向目标运动
2. **切换点**：在到达中点前某位置，舵机反向全速旋转
3. **减速段**：摆杆倾角反向，产生 -a_max 减速度
4. **到达**：速度降为 0，位置 = y

```
       加速段           减速段
   a_max →→→→→→→ ┊ ←←←←←← -a_max
   v: 0→vmax ┊ vmax→0
   x: x₀→x_switch ┊ x_switch→y
```

**切换条件**：当 |y - x| = v²/(2a_max) 时应开始减速。

### 实际硬件约束

### SG90 360° 舵机
| 参数 | 值 | 说明 |
|------|-----|------|
| 最大转速 | ~60rpm (1rps) | 无负载，5V |
| 响应时间 | 50~100ms | 从停止到目标速度的机械延迟 |
| 死区 | ±5~10us | 1500us附近不转 |

→ 摆杆倾角变化速率 ≈ 舵机转速 × 传动比。假设直驱：360°/s = 6.28 rad/s。

### MaixCAM 相机
| 参数 | 值 |
|------|-----|
| 帧率 | 10fps = **100ms/帧** |
| 延迟 | 采集+处理+传输 ≈ 100~150ms |

→ **相机是系统带宽瓶颈**。100ms 内小球可能移动数厘米。

### 时间量级估算

摆杆倾角 θ = 5° ≈ 0.087 rad 时：
- 小球加速度 a = g·θ = 9.8 × 0.087 ≈ 0.85 m/s²
- 100ms 内位移 ≈ ½at² = 0.5×0.85×0.01 ≈ 4mm
- 要移动 5cm：½at² = 0.05 → t = √(0.1/0.85) ≈ 0.34s → 约 3~4 帧

→ 系统响应足够完成任务（5s 时限，3~4 帧可控），但反馈延迟必须补偿。

## 延迟补偿策略

相机 100ms+ 延迟意味着看到的位置是 100ms 前的位置。补偿方法：

1. **带延迟的 PID**：`error = target - (measured + v_est * delay)`
   - 用上一帧和当前帧差分估计速度 v_est
   - 预测当前实际位置 = measured + v_est × 0.1s
2. **降低增益**：延迟大时 KP 必须小，否则过冲振荡
3. **前馈主导**：根据误差方向直接给 80% 舵机速度，PID 只做 20% 修正
4. **到位死区**：|error| < 2mm 时锁舵机，等相机确认

## 简化控制策略（10fps 可用方案）

```
每 100ms 收到相机位置 pos：

1. err = target - pos
2. 如果 |err| < 2mm → Servo_Stop(), 等待下一帧
3. 否则：
   a. 前馈 = sign(err) * 70% 最大转速    // 粗调
   b. P项  = KP * err                     // 细调
   c. Servo_SetSpeed(前馈 + P)
4. 如果有连续3帧 |err| 在缩小 → 减半速度防过冲
```

|err| > 3cm 时全速 bang-bang，< 3cm 时降速精细调节。
